# Booking System - Frontend

A modern, responsive web interface for managing customer bookings. Built with **Next.js**, **Tailwind CSS**, and **Lucide React**.

## 🚀 Features
- **Booking Dashboard**: View all current bookings in a responsive table.
- **Real-time Updates**: Create new bookings and update statuses without page refreshes.
- **Status Management**: Toggle booking statuses between `pending`, `confirmed`, and `cancelled`.
- **Validation**: Frontend handling for date-time synchronization with the API.

## 🛠️ Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Data Fetching**: Standard Fetch API
